## Objetivo

Consolidar os oito pontos da revisão AQUA Foundation numa release candidate rastreável. Esta ficha não autoriza deployment.

## Tipo e compatibilidade

Release interna de arquitetura e segurança. A API `/v1` é compatível; rotas legacy estão deprecated. Billing portal e publicidade continuam suspensos.

## Componentes

- Produto React/Vite e gateways Vercel/Cloudflare/local.
- AQUA OS API, Commerce, Data, Trust e Observability.
- Supabase Auth/PostgreSQL, Stripe e fornecedores opcionais de analytics/ads.

## Testes

- Smoke tests funcionais, privacidade e operações.
- Build Vite de produção.
- Testes de domínio Commerce e Data Platform.
- Validação OpenAPI, contratos JSON e sintaxe TypeScript.
- Dependency audit concluído sem vulnerabilidades conhecidas.

## Migração e rollback

Executar as migrations por serviço em staging e conservar scripts/backup de rollback antes de produção. Código pode reverter para a release anterior; alterações de dados exigem plano específico e nunca `DROP` improvisado.

## Critérios de aprovação

- Quality gate e checklist de deployment completos.
- Migrations, RLS, retenção, Auth e Stripe validados em staging.
- CMP certificada configurada ou AdSense mantido suspenso.
- Health, dashboard e alertas operacionais ativos.
- Aprovações Architecture, Engineering, Product, Security/Privacy e Operations.
